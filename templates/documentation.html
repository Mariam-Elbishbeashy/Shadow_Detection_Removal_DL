Installation

Follow these steps to set up the ShadowRemove application on your system.

1

Prerequisites

  • Python 3.8 or higher
  • pip (Python package manager)
  • Git
2

Clone the Repository

git clone https://github.com/yourusername/shadow-remove.git
cd shadow-remove
3

Create Virtual Environment

# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
4

Install Dependencies

pip install -r requirements.txt
5

Initialize Database

python init_db.py
6

Run the Application

python app.py

The application will be available at http://localhost:5000

Shadow Detection

The shadow detection system uses a deep learning model based on VGG16 architecture with custom modifications for shadow detection.

Technical Approach

The detection model uses:

  • Transfer learning with VGG16 as base model
  • Dilated convolutional blocks for larger receptive fields
  • Squeeze-and-excitation blocks for channel-wise attention
  • U-Net like architecture with skip connections

Training Process

The model was trained on the ISTD dataset with data augmentation:

  • Horizontal flipping
  • Brightness adjustment
  • Rotation
  • Contrast changes

Shadow Removal

The shadow removal algorithm uses histogram matching and edge blending to seamlessly remove shadows from images.

Algorithm Steps

  1. Shadow Mask Generation: Use the detection model to identify shadow regions
  2. Border Region Identification: Identify transition areas around shadows
  3. Histogram Matching: Adjust shadow region histograms to match border regions
  4. Edge Blending: Smooth transitions between adjusted and original regions

AI Models

The application uses pre-trained deep learning models for shadow detection.

Model Details

  • Base Model: VGG16 with ImageNet weights
  • Input Size: 384×512 pixels
  • Output: Binary mask of shadow regions
  • Training Dataset: ISTD (ISTD Dataset)

Performance Metrics

The model was evaluated using:

  • Dice Coefficient: 0.85+
  • IoU (Intersection over Union): 0.80+
  • Accuracy: 95%+

Model Files

The application looks for the following model files:

  • shadow_model2_0850_K2S2E5_aug.h5 - Pre-trained detection model
  • If not found, the application will build and train a new model

Troubleshooting

Common issues and their solutions:

Installation Issues

TensorFlow installation fails

Try installing a specific version compatible with your system:

pip install tensorflow==2.13.0

Runtime Issues

Model not found error

The application will build a new model if the pre-trained model is not available. This may take several minutes.

Memory errors with large images

Resize very large images before uploading or increase your system's available memory.

Performance Tips

  • Use images with reasonable dimensions (under 2000px on the longest side)
  • Close other memory-intensive applications when processing large images
  • For best results, use images with clear lighting and distinct shadows
